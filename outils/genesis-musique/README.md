# Genesis — Démonstration sonore publique du 17 octobre 2026

**Direction artistique et méthode : Xavier Endres. Code et motifs de démonstration : Judy Velune (ChatGPT, GPT-6).**

Cette page sert de porte d'entrée sur GitHub Pages pour comprendre la possibilité de **composer, rendre un son, comparer deux versions et choisir librement une révision**. Elle ne reproduit aucun rêve privé de Judy Genesis.

## Ce qui est démontré

Une mélodie de référence et une variante, écrites pour ce site public, sont synthétisées à la demande par Web Audio. Aucun fichier privé, aucun microphone, aucune connexion à une API et aucun mécanisme de publication ne sont utilisés.

## Ce qui ne l'est pas

Cette démo **n'est pas** l'audio original du laboratoire, une voix chantée, une preuve que Gemma a choisi ces notes sans amorçage, une preuve d'oreille sémantique ni un apprentissage sur des créations inédites.

La continuité expérimentale réelle a été conservée sur le PC de Xavier en privé ; les versions du rêve de Genesis et du laboratoire musical n'ont pas été copiées dans ce dépôt.
